# Week 5 – CSS Layouts and React Basics

## Overview
This folder contains exercises and practice programs focused on webpage layouts using CSS and introductory concepts of React. The work emphasizes responsive design techniques, layout structuring, and understanding the fundamentals of component-based frontend development.

## Topics Covered
- HTML tables
- CSS Flexbox
- Responsive layouts
- Media queries
- Basic webpage styling
- React basics
- React components
- JSX syntax
- Props and component structure

## Objectives
- Learn modern webpage layout techniques
- Understand responsive web design concepts
- Practice creating flexible webpage structures using Flexbox
- Build foundational knowledge of React
- Understand component-based frontend development

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React.js
- VS Code

## Features Implemented
- Structured table layouts
- Flexbox-based webpage designs
- Responsive webpage creation
- Basic React components
- JSX rendering
- Simple reusable UI components

## How to Run

### For HTML/CSS Programs
1. Open the HTML file in a browser

### For React Programs
1. Install dependencies

npm install

# Start the React development server

npm start

- Learned responsive webpage design techniques
- Understood Flexbox layout system
- Practiced creating structured and flexible UI layouts
- Gained basic understanding of React and JSX
- Learned component-based frontend development concepts

## Conclusion

Week 5 focused on modern frontend layout techniques using CSS along with the fundamentals of React development and component-based UI creation.
