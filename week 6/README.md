# Week 6 – State Management and Employee Management Application

## Overview
This folder contains projects and exercises focused on React state management and the development of a full-stack MERN Employee Management Application. The work emphasizes frontend-backend integration, dynamic data handling, and application state management.

## Topics Covered
- React state management
- useState Hook
- useEffect Hook
- Component communication
- Props handling
- Form handling
- CRUD operations
- MERN stack fundamentals
- REST API integration
- MongoDB database connectivity
- Express.js backend development
- Employee management system development

## Objectives
- Understand state management in React
- Learn frontend and backend integration
- Practice CRUD operations in a MERN application
- Build dynamic and interactive applications
- Improve full-stack development skills
- Understand API communication between client and server

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript
- HTML5
- CSS3
- VS Code

## Features Implemented
- Employee data management
- Add employee functionality
- Update employee details
- Delete employee records
- Dynamic state updates
- REST API communication
- Backend database integration
- Form validation and handling
- React component-based architecture
