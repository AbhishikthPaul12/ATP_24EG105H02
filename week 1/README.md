# Week 1 – Basic JavaScript Programs

## Overview
This folder contains beginner-level JavaScript programs focused on problem solving, conditional statements, arrays, loops, and functions. These programs were implemented as part of practice exercises to strengthen programming fundamentals.

## Topics Covered
- Conditional statements
- Loops
- Arrays
- Functions
- Basic mathematical operations
- Problem-solving techniques

## Programs Included
1. Biggest of Two Numbers
2. Biggest of Three Numbers
3. Sum of the Array
4. Smallest Element of the Array
5. Sum of Array Using Function
6. Additional basic array and number problems

## Technologies Used
- JavaScript
- Node.js

## IDE
- VS Code

## How to Run
1. Install Node.js
2. Open terminal in the project folder
3. Run the file using:

node filename.js

Example:

node biggestOfTwoNumbers.js

## Learning Outcomes

* Learned JavaScript syntax and structure
* Understood how to use functions and arrays
* Improved logical thinking and problem-solving skills
* Practiced writing clean and simple code
