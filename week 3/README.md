# Week 3 – Product REST API and MongoDB Practice

## Overview
This folder contains the development of a Product REST API along with MongoDB query practice programs. The work focuses on backend development concepts including schema creation, CRUD operations, database connectivity, and RESTful API design using JavaScript technologies.

## Topics Covered
- REST API development
- Product API creation
- MongoDB basics
- MongoDB queries
- CRUD operations
- Schema design
- Database connectivity
- API routing
- JSON data handling
- Backend development fundamentals

## Objectives
- Understand REST API architecture
- Learn how to create and manage product schemas
- Practice CRUD operations using MongoDB
- Improve backend development skills
- Learn database query execution and data handling
- Understand server-client communication

## Technologies Used
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- VS Code

## Features Implemented
- Product schema creation
- REST API routes
- Create, Read, Update, Delete operations
- MongoDB query practice
- Database integration using Mongoose
- JSON request and response handling
- API testing and debugging

## API Functionalities
- Add new products
- Retrieve product details
- Update existing products
- Delete products
- Handle database queries efficiently

## MongoDB Concepts Practiced
- Insert queries
- Find queries
- Update queries
- Delete queries
- Filtering and searching documents
- Collection handling
