# Week 2 – JavaScript Concepts and REST API

## Overview
This folder contains JavaScript programs and examples focused on intermediate JavaScript concepts and modern ES6 features. The exercises were designed to improve understanding of objects, arrays, copying techniques, modules, asynchronous behavior, and REST API fundamentals.

## Topics Covered
- Arrays and array methods
- JavaScript objects
- Shallow copy and deep copy
- Spread operator
- JavaScript modules
- Timer functions (setTimeout, setInterval)
- REST API basics
- Asynchronous programming concepts

## Objectives
- Understand how arrays and objects work in JavaScript
- Learn the difference between shallow copy and deep copy
- Practice using the spread operator for copying and merging data
- Understand modular programming using JavaScript modules
- Learn asynchronous execution using timer functions
- Gain basic knowledge of REST APIs 

## Technologies Used
- JavaScript (ES6+)
- Node.js


## IDE
- VS Code

## Concepts applied
- REST API concepts

## Features Implemented
- Array traversal and manipulation
- Object creation and modification
- Copying objects and arrays using spread operator
- Module import and export
- Timer-based execution using asynchronous functions
- Making basic requests to the APIs

## How to Run
1. Install Node.js
2. Open terminal in the project folder
3. Run the file using:

node filename.js

Example:

node app.js

## Learning Outcomes

* Improved understanding of modern JavaScript concepts
* Learned practical usage of objects and arrays
* Understood shallow copy vs deep copy behavior
* Practiced asynchronous programming concepts
* Gained introductory knowledge of REST APIs 
* Improved debugging and code organization skills

## Conclusion

Week 2 focused on building a strong foundation in intermediate JavaScript concepts and modern ES6 features through practical coding exercises and API-based learning.
